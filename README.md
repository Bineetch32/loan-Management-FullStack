# Loan Management Full Stack

Full-stack Home Loan Management application using Angular and Spring Boot.

## Structure

- `backend/` - Spring Boot REST API
- `frontend/` - Angular application, to be added next

## Backend Stack

- Java 17
- Spring Boot 2.7.4
- Spring Data JPA
- MySQL
- Spring Mail
- Maven

Real local credentials are not stored in Git. Use `backend/src/main/resources/application-example.properties` as the configuration template.
